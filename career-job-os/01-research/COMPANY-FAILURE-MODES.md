# Per-company-type shortlist failure modes

## Amazon
- Death gate: recruiter level map + credibility
- Needs: L4-appropriate scope, LP-shaped metrics, Java/Python + AWS specifics
- Rejects: senior-sounding claims from small employers without proof

## Microsoft
- Death gate: human relevance after referral
- Needs: Job ID stack match, believable scope, coding signal
- Rejects: “AI hyperscale infrastructure” on 2.5 YOE consulting

## Adobe
- Death gate: Workday rank + lane fit
- Needs: product-relevant backend story
- Rejects: generic services Java with no product signal

## Akamai
- Death gate: domain mismatch / fabricated networking identity
- Needs: real systems/networking proof
- Rejects: JD-mirrored Go/zero-trust without LinkedIn support

## Nutanix
- Death gate: YOE + systems depth hard filter
- Needs: OS/storage/distributed systems depth
- Rejects: “eager to learn OS internals” at mid levels

## Wells Fargo
- Death gate: Workday + inconsistency + repeat apply noise
- Needs: stable enterprise narrative matching exact JD
- Rejects: shifting Python-AI rewrite of same jobs

## JPMorganChase
- Death gate: volume + packet crispness
- Needs: Java fintech consistency, location, HackerRank readiness after
- Rejects: AI-tool flex, weak brand without sharp metrics

## Mastercard
- Death gate: trust (overclaim)
- Needs: honest payments-adjacent backend, not invented fraud expert
- Rejects: billions/month + sub-ms + Oracle cosplay

## PayPal
- Death gate: over-tailored full-stack reshape
- Needs: truthful full-stack or backend match to JD
- Rejects: GraphQL/DynamoDB invention if not true

## GROWW
- Death gate: ownership authenticity
- Needs: end-to-end product ownership language that is true
- Rejects: architecture theater without product proof
