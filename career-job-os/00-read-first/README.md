## Critical honesty (read before anything else)

**There is no 100% job guarantee.** Anyone promising one is lying.

This OS maximizes probability by fixing the real failure mode: **resume/LinkedIn credibility + wrong targeting + weak referral process + unready interviews**.

Expected honest ranges (India, 2026 research synthesis):
- Cold apply → interview: ~1–5%
- Referral → interview: often **10–20×** better than cold
- Interview → offer: ~15–25% (prep-dependent)
- Time to offer (upward move): often **8–20 weeks** with consistent execution

**Success condition for this OS:** shortlists start appearing within 2–4 weeks of using ONE master truth resume; offers become plausible within 8–16 weeks if prep + volume + referrals run in parallel.

## How any agent must work (low context)

1. Read `00-read-first/AGENT-CONTRACT.md` (mandatory).
2. Read `02-truth/MASTER-TRUTH.md` (locked facts — never invent).
3. Read `02-truth/FORBIDDEN-CLAIMS.md` (never write these).
4. Use only the prompt in `06-prompts/` that matches the task.
5. Update trackers in `08-trackers/` and changelog in `12-updates/CHANGELOG.md`.
6. Never rewrite primary language, scale, or domain to match a JD.

If context is tiny: **only open the specific prompt file + MASTER-TRUTH + FORBIDDEN-CLAIMS**.  
If the task involves user pastes or history: also open `13-source-data/README.md` and never skip archiving.
