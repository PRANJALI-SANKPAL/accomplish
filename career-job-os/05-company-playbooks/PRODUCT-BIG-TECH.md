# Playbook — Product Big Tech (Amazon / Microsoft / Adobe)

## When to use
SDE/SWE roles in India product orgs, ~1–4 YOE reqs.

## Fit prerequisites
- Master Truth Java/Python backend matches JD ≥70%
- Level: prefer SDE1 / L4 / early SDE2 — avoid senior if YOE <4 unless JD says 2+
- Coding prep active (cannot bluff OA)

## Resume emphasis
- Ownership + metrics (ClickHouse, Demand Planning)
- AWS service names if true
- Avoid AI-infra / staff tone
- Amazon: bake Ownership/Dive Deep/Deliver Results into bullets naturally

## Process expectations
1. Apply + referral same day if possible
2. OA likely (coding)
3. Loops: coding + behavioral (+ design for mid)

## Referral ask
Use Job ID + 2 sentences from Master Truth. Never “any SDE role.”

## Do not
- Send Microsoft AI hyperscale resume
- Claim Bar Raiser readiness without mocks
- Re-apply same req within cooldown after loop fail
