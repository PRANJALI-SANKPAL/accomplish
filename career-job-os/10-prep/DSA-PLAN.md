# DSA plan (pattern-first)

Target for product/GCC interviews: **150–250** quality problems, not 500 random.

## Weekly cadence

- 10–15 problems/week while working
- Always timed after week 2
- Redo fails after 3–5 days

## Pattern order (complete before moving on)

1. Arrays / Hashing
2. Two Pointers / Sliding Window
3. Binary Search
4. Stack / Monotonic
5. Linked List
6. Trees / BST
7. Heaps
8. Graphs (BFS/DFS)
9. Union Find
10. Recursion / Backtracking
11. Dynamic Programming (1D → 2D)
12. Intervals / Greedy
13. Tries (as needed)
14. Bit / Math misc (light)

## Language

Prefer **Java** for India product/bank loops (aligns resume). Python OK if faster and fluent.

## Milestones

- Week 2: patterns 1–4 comfortable
- Week 6: through graphs; mixed timed sets
- Week 8+: mocks + company tags
- Maintenance: 4–5 problems/week once interviewing heavily

## Resources (pick one primary)

- NeetCode roadmap / pattern lists
- Company-tagged LeetCode after mocks reveal gaps
