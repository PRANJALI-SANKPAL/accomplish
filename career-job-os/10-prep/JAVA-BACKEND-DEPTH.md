# Java backend interview depth checklist

Be ready to explain with examples from your work:

## Core Java
- [ ] Collections internals (HashMap, ArrayList, ConcurrentHashMap)
- [ ] equals/hashCode
- [ ] Immutability
- [ ] Generics basics
- [ ] Exceptions

## Concurrency
- [ ] threads vs executors
- [ ] synchronized / locks
- [ ] race conditions, deadlocks
- [ ] when you used async/messaging instead of threads

## Spring
- [ ] IoC/DI
- [ ] Bean scopes
- [ ] REST controller → service → repository
- [ ] Transactions / @Transactional pitfalls
- [ ] JPA N+1 and fixes

## Data
- [ ] Indexing, EXPLAIN basics
- [ ] Why ClickHouse vs MySQL for analytics
- [ ] Redis patterns you used
- [ ] Migration/cutover risks

## Production
- [ ] Logging/metrics approach
- [ ] Incident story
- [ ] Docker deploy basics
- [ ] CI/CD what you touched
