# Daily operating system

**Exact clicks for today:** `START-HERE-APPLY-TODAY.md`  
**Full reference:** `APPLY-PLAYBOOK.md`

## Non-negotiable daily block (90–150 min)

### Block A — Prep (45–60 min)
1. Timed DSA medium (`10-prep/DSA-PLAN.md`)
2. Log `08-trackers/prep-log.csv`

### Block B — Source (20 min)
1. LinkedIn Jobs + Hirist + Instahyre + next company from Top 10 / backup queue
2. Collect 8–12 roles → keep **5** with fit≥70

### Block C — Refer + apply (40–60 min)
For each of 5 roles:
1. Prompt/score fit if unsure (`06-prompts/01`)
2. Referral DM (Job ID + 2 true sentences) — `09-templates/REFERRAL-MESSAGES.md`
3. Apply on official portal with Backend or Full Stack v1
4. Log `applications.csv` + `referrals.csv`

### Block D — Close (5 min)
Mark status in `11-lists/COMPANY-WATCHLIST.md`. Write tomorrow’s next 5 from Top 10 / backup.

## Minimum day (low energy)
1 DSA + 2 referrals + 2 applies + log.
