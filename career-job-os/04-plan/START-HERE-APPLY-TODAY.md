## HOW to apply (one role = this checklist)

Copy this for every single application:

```text
[ ] 1. Open role → copy Job title + Job ID + company + apply URL
[ ] 2. Fit ≥70%? (Java/Spring or Python backend, 2–4 YOE, product/fintech/SaaS)
       If no → SKIP. Do not force-fit.
[ ] 3. Pick PDF: Backend (default) OR Full Stack (FE-heavy JD only)
[ ] 4. LinkedIn: search "{Company} Software Engineer" → 1–2 people (2nd degree preferred)
[ ] 5. Send referral DM (paste Template A from 09-templates/REFERRAL-MESSAGES.md)
[ ] 6. Same day: submit on career page / LinkedIn Easy Apply / board
[ ] 7. Log one row in 08-trackers/applications.csv
[ ] 8. Log referral in 08-trackers/referrals.csv
[ ] 9. Set calendar/reminder: follow up in 10 business days
```

**Fit quick test (no agent needed):**
- YES if: Backend/SDE, Java or Python, microservices/APIs, 2–5 YOE, India or remote-OK
- NO if: 5–8+ YOE required as hard min, networking/edge/OS internals, fraud specialist, Staff/Principal, Go-only expert, “must have X years Kubernetes lead”
