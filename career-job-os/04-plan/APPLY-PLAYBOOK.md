## 2) HOW to apply (exact process every role)

### Step-by-step (15–25 min per role)

```text
1. Find role (LinkedIn/Hirist/Instahyre/career page)
2. Copy Job ID + JD text
3. Run fit score (prompt 01) — STOP if <70
4. Pick resume: Backend v1 OR Full Stack v1
5. Find 1–2 employees (LinkedIn: company + "Software Engineer" + 2nd degree)
6. Send referral ask within 24h (template 09-templates/REFERRAL-MESSAGES.md)
7. Same day: apply on official portal (don’t wait forever for referral)
8. Log applications.csv + referrals.csv (prompt 05)
9. Set next_action_date = +10 business days
```

### 24-hour referral rule

| Time | Action |
|---|---|
| Hour 0 | Role found |
| Hour 0–24 | Referral DM sent (Job ID + 2-sentence true fit) |
| Hour 24 | Apply on portal even if no reply |
| Day 5 | One polite follow-up to referrer |
| Day 10+ | Follow up application / move on |

### Search queries to use (copy-paste)

**LinkedIn / Hirist / Naukri:**
```text
Java Spring Boot Backend "2-4 years" OR "2-5 years"

```

**Remote-from-India (US/UK/EU) searches on LinkedIn:**

## 4) WHAT to do — daily / weekly schedule

### Daily (90–150 min after work)

| Block | Minutes | Exact actions |
|---|---|---|
| A — DSA | 45–60 | 1 timed medium (`10-prep/DSA-PLAN.md`); log `prep-log.csv` |
| B — Source | 20 | Find 8–12 roles → triage to **5** fit≥70 |
| C — Refer + apply | 40–60 | 3 referral asks + 5 portal applies; log CSV |
| D — Admin | 5 | Tomorrow’s 5 company names written |

**Daily minimum if tired:** 1 DSA + 2 referral asks + 2 applies.

### Weekly (Saturday 60–90 min)

1. Count apps / referrals / replies / OAs  
2. Response rate = (replies+OAs) / apps  
3. If rate **&lt;3% after ≥30 apps** → resume/LinkedIn audit (prompt 12)  
4. Re-upload **same** Backend v1 on Naukri  
5. Follow up apps ≥10 business days silent  
6. Add 5 new Tier A companies to watchlist  
7. Fill `12-updates/WEEKLY-REVIEW-LOG.md`

### Weekly volume targets

| Metric | Target |
|---|---|
| High-fit applications | 25–40 |
| Referral asks | 15–25 |
| DSA problems | 10–15 |
| STAR stories polished | 1 |
| Mocks (from week 6) | 1 |
