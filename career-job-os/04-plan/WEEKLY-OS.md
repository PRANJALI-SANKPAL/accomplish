# Weekly operating system (Saturday review)

## Metrics to compute

- Applications sent this week
- Referral asks / replies / referrals submitted
- Recruiter replies / OA invites / interviews
- Response rate = (replies+OAs) / applications
- DSA problems solved; patterns covered
- Mocks done

## Decisions

| Signal | Action |
|---|---|
| Response rate < 3% after ≥30 apps | Re-audit resume + LinkedIn; pause FAANG volume |
| Response rate 5–15% | Maintain; increase referrals |
| Interviews but OA fail | Shift time to DSA timed sets |
| Interviews fail behavioral | STAR bank rebuild |
| Interviews fail design | LLD/HLD block |
| Same company rejected 2+ | Cool off; don’t spam |
